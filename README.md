# Flip the Coin

A simple and interactive coin flipping application built with HTML, CSS, and JavaScript.

## Features
- Random coin flipping.
- Manual Heads/Tails toggling.
- Smooth coin flip animation.
- Responsive design.
- Interactive button and coin.

## Technologies Used
- HTML5
- CSS3
- JavaScript
